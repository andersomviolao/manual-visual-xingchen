# Manual visual Xingchen — português do Brasil

Guia interativo de estudo das telas do bot Android Xingchen para Clash of Clans. Revisão **1382 — 13/11/2026**: 46 definições XML comparadas com a 1380; retorno de Forjar moedas da Capital em Tarefas gerais.

O site publicado pelo GitHub Pages usa `docs/`. Abra `docs/index.html` para consulta local. Consulte [as instruções](docs/r/76cfbee3/6c1467cc/9dcba57b936db06b.md) e [o registro da revisão e origem do APK](docs/r/59cb846d/eb8decd9/ece7da70e15f2406.md).

Download do aplicativo: https://921015.xyz/ → 辅助游戏下载 → 辅助下载. O instalador 1382 foi baixado do botão oficial e conferido localmente. APKs e backups ficam em `instaladores/`, fora do GitHub.

A simulação não executa o bot nem ações no jogo. O PDF em português foi revisado em **12/11/2026**: preserva a tradução do manual histórico e inclui as atualizações oficiais até 1380. O original chinês foi novamente exportado e comparado nas 24 páginas, sem novas instruções identificadas. Veja [a conferência do manual](docs/r/c2d083cb/d0cd5012/4dd359b582940928.md).

O guia inclui uma tela de senha. É uma barreira visual no navegador, sem autenticação de servidor: os arquivos continuam acessíveis diretamente no GitHub Pages ou no repositório.

Ferramentas de manutenção em `ferramentas/`, fora da pasta publicada. Execute `python ferramentas/gerar.py`, `./ferramentas/preparar-publicacao.ps1` e os verificadores `.cjs` dessa pasta. Os caminhos opacos são estáveis e registrados para manutenção. A reorganização dificulta acesso casual, mas não fornece autenticação nem oculta o histórico Git.
