# Xingchen — 星辰辅助 / 星辰国际 — manual em português

![Ícone original do aplicativo chinês Xingchen — 星辰辅助 / 星辰国际](docs/bot-icon.png)

Um guia em português para entender as telas e opções do **Xingchen**, o bot chinês para **Clash of Clans (部落冲突)**. Aqui você encontra um manual em PDF e uma simulação das telas do aplicativo para explorar pelo navegador, no celular ou no computador.

## Acesse aqui

- **[Abrir o guia interativo em português](https://andersomviolao.github.io/manual-visual-xingchen/)**
- **[Ler o manual em português — PDF](https://andersomviolao.github.io/manual-visual-xingchen/Manual_Xingchen_Portugues_BR.pdf)**
- **[Visitar o site original do bot — 星辰国际辅助官网](http://xccoc.fun/)**
- **[Baixar o APK pelo endereço indicado no site original](https://921015.xyz/fz)**

O link de download usa o endereço contínuo do autor, sem fixar uma versão específica no README. Ele entrega a versão que o autor disponibilizar nesse endereço.

## Como usar o guia

1. Abra o guia interativo pelo link acima.
2. Toque no ícone **Xingchen** e confirme a entrada.
3. O painel abre diretamente. Explore as opções traduzidas.

Na tela inicial também há atalhos para abrir o manual em português e baixar o bot. Em **Opções da simulação**, você pode alternar entre português e chinês para comparar os termos.

Este é um projeto independente de tradução e estudo. A página reproduz as telas para consulta; as ações no navegador são simuladas. O aplicativo Android original é distribuído pelo site do autor.

## Nome do bot em chinês

O site original apresenta o aplicativo como **星辰辅助** e **星辰国际**. Estes termos ajudam a reconhecer o mesmo bot em páginas, tutoriais e buscas:

- **星辰辅助** — Xingchen, assistente/bot.
- **星辰国际** — Xingchen Internacional.
- **星辰国际辅助** — nome completo usado para identificar o assistente.
- **部落冲突** — nome chinês de Clash of Clans.
- **星辰辅助 使用教程** — tutoriais de uso do Xingchen.
- **星辰辅助 葡萄牙语说明** — explicações do Xingchen em português.

**中文简介：** 本项目提供星辰辅助（星辰国际 / 部落冲突辅助）的葡萄牙语说明、PDF 手册和网页界面模拟，方便对照中文与葡萄牙语选项。原版应用请访问作者网站。
