## Organização e manutenção

- `docs/`: versão publicada no GitHub Pages, com o guia e seus recursos.
- `materiais/guia-offline/`: cópia local do guia, fora do Git.
- `materiais/manuais/`: documentos de origem locais.
- `instaladores/`: APK atual e backup anterior; fora do GitHub.
- `ferramentas/interfaces-originais.json`: 46 XML originais do APK de referência.
- `ferramentas/traducoes.json`: traduções das definições.
- `ferramentas/conferencia-1382.json`: registro da comparação e origem.

Edite os arquivos em `docs/`. Para regenerar dados, execute `python ferramentas/gerar.py`; depois `./ferramentas/preparar-publicacao.ps1`. Valide com `node ferramentas/verificar-publicacao.cjs` e `node ferramentas/conferir-layout.cjs` (Node.js, Playwright e Edge). APKs e scripts de automação do jogo não são publicados.

O guia inclui uma tela de senha. É uma barreira visual no navegador, sem autenticação de servidor: os arquivos continuam acessíveis diretamente no GitHub Pages ou no repositório.
